# ADR 0001: Web Router

## ステータス

採用。

## 決定

HTTP ルーティングには Echo v4 を使う。

## 背景

最初の実装では、API の範囲が小さく固定されていたため、Go 標準の `net/http`
ルーターを使っていた。

- `/v1/todos` 配下の TODO CRUD
- `/health`
- `/ready`
- `/version`

現在は HTML template と static asset も配信し、hot reload には Air を使っている。

さらに後続フェーズでリクエスト ID、アクセスログ、セキュリティヘッダー、ヘルスエンドポイントを追加する予定である。

Echo v4 は軽量なフレームワークであり、ハンドラーを標準的な HTTP の考え方に近く保ちながら、ルートグループ、パスパラメータ、ミドルウェアをサポートする。Echo v5 ではなく Echo v4 を選ぶのは、v4 が安定しており、現在もメンテナンスされているためである。

## 結果

- フレームワーク依存が 1 つ追加される。
- ルートパラメータとグループ化したルートがシンプルになる。
- 今後のミドルウェアは Echo のミドルウェアパターンを使える。
- サービスレイヤーとリポジトリレイヤーはフレームワークに依存しないままにする。
