# ADR 0005: カーソルページング

## ステータス

採用。

## 決定

`created_at` と `id` に基づくカーソルページングを使う。

## 背景

row が insert または delete されるとオフセットページングは不安定になる。この API では`created_at` を主な sort key にしながら、安定したページネーションが必要である。

## 結果

- カーソルはエンコードし、検証する必要がある。
- 不正なカーソルは `400 Bad Request` を返す。
- インデックスは `(created_at, id)` と status で絞り込む query をサポートする必要がある。
